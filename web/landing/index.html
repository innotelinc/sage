It listens, watches, reads, then decides.

Four ways in, one persona out. Everything it perceives is folded into the same memory, so a slide and a sentence from ten minutes ago can answer the question being asked now.

🎙

Listening

Live lecture transcript through on-device speech recognition, chunked into notes that keep definitions, numbers and the words EXAM: — everything the instructor stressed.

🖥

Watching

Screen share, phone camera, or an uploaded screen recording. Frames are sampled and read as they change, so a whiteboard becomes notes while it is being written.

📖

Reading

Slides, photographs, handouts and pasted chapters become study notes with the formulas exactly as given, likely exam questions, and the gaps the material leaves.

⚖️

Evaluating

It commits to an answer with a confidence score and the reason it knows, rather than hedging. Ambiguity gets the most likely reading and one clause saying so.

✍️

Writing

Quizzes answered one decision at a time, and essays with a real argument — citing only the material you supplied, never inventing a reference.

🧬

Evolving

After class it reviews its own notes and rewrites its behaviour: how this instructor grades, which answer shape earned marks, how you like to sound.

What it can actually capture.

No hand-waving: a web page cannot read an iPhone screen or a cast stream. Here is exactly what works, checked against what the browser exposes.

Mic and screen capture need a secure context: https:// or localhost. A bare LAN address loads the interface but not the capture.

One gateway, every model.

SAGE speaks plain OpenAI-compatible HTTP, so the gateway is a base URL and a key — nothing else. This build ships wired to Innotel OmniRoute.

  • Endpoint — https://gateway.innotel.us/v1
  • Verified model — agy/gemini-3-flash, text and vision in about a second
  • Keys — subscribe.innotel.us
  • Anywhere else — OpenAI, Groq, OpenRouter or a local Ollama, via AI_BASE_URL
The key's allowlist is the real contract. The gateway lists 1,249 models, but a key routes only the connections it is scoped for. On this key every audio model sits behind an openrouter connection that is excluded, so server transcription answers 403 — SAGE detects that once and falls back to on-device speech recognition instead of retrying forever.
verify any model before trusting it
$ curl -s https://gateway.innotel.us/v1/chat/completions \
    -H "authorization: Bearer $KEY" \
    -H "content-type: application/json" \
    -d '{"model":"agy/gemini-3-flash","messages":[{"role":"user","content":"OK"}]}'

Runs on what you already have.

Plain Node with no dependencies, or a Cloudflare Worker — the same src/app.mjs handler serves both. The phone app is the same page, added to the home screen.

🧩

Persona is a file

src/persona.mjs holds the identity rules and one contract per task: note, answer, quiz, essay, read, phrase, evolve.

🔐

Secrets stay server-side

The key lives in .env, gitignored and never served — the browser only ever talks to your own API.

📱

Installable

A PWA with a manifest and offline shell. Add to Home Screen and it opens standalone, with its own icon.

It keeps reading while you keep studying.

The hard part is not answering a question — it is answering one while another app owns the screen. Study mode runs listening and watching together and answers unprompted; the relay covers devices that cannot capture themselves.

🎧

Study mode

One toggle: microphone and screen together, notes accumulating, and an answer offered the moment a question lands — throttled to one every 45 seconds so it stays quiet.

🔗

Relay

A computer sharing a mirrored phone or a TV cast window publishes frames under a short code. Your phone joins the code and does the thinking, with the course app still in front.

📱

Android, directly

Android Chrome can capture the whole device: start Watch, switch to the course app, and the frames keep arriving — screen and audio together.

Roadmap.

Shipped is shipped; the rest is named honestly.

v1.0

Listening, watching, reading, quiz and essay surfaces, self-evolution memory, gateway wiring, PWA install.

v1.1

Study mode with automatic question detection, and the cross-device relay for mirrored phones, tablets and cast windows.

v1.2

The best model the key can actually call is chosen for you — no model setting to get wrong — and a session bought at Magnate installs itself from its receipt.

v1.3

Per-task routing: running notes go to the fastest model the key can call, answers and essays to the strongest — both picked automatically.

v1.4

The session clock: the minutes left on a bought session are on screen, and capture stops by itself when the window closes.

v1.5

Capture that survives playback: the microphone is reclaimed when a video interrupts it, a screen recording imports and reads in one tap, Settings closes with an ✕ and never opens itself, and a question's photo is cleared after the answer.

v2.0

The operator panel: the access code, model routing and a seven-day usage tally behind Cerulean SSO — set from a phone, no restart.

v2.8

Foundation documents: a course carries its own PDFs, Word files, screenshots and recordings, read once and then used to ground Answer, Quiz and Read.

v2.9

Grounded essays: the documents reach Essay too, and a grounded reply names the files it leant on.

v3.0

A question survives the network: if the server cannot be reached it is kept on the device and answered when the connection comes back, in the tab that asked.

v3.1

Essay takes photographs: the prompt, a handout or a page of handwritten notes is attached instead of typed, read before a word is written, then cleared so the next essay never inherits it.

v4.0

Capture that outlives the app: a ReplayKit broadcast extension keeps reading the screen with Sage in the background or the phone locked, Android keeps its foreground service, and the server joins the two.

v4.1

A kept turn keeps its photos: a question photographed with no signal is stored with its images, replayed once with the picture attached, and the images are dropped when the answer lands.

v4.2

A citation you can turn to: a reply names the page it used as [file p.N], and the page opens from the copy the course already holds — never an invented page.

v4.3

Exam rehearsal: a timed paper set from the course, sat in the app with the clock running, and marked question by question — with no answer on the page before you submit.

v4.4

Audio-only lectures: notes from a recording with no screen, each stamped with the moment it came from — and the recording kept on the device, so a note replays it at that offset.

v4.5

One search across every course: a phrase finds the note, the answer and the page it was taught on — on the device, and each hit opens where it came from.
